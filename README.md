# FPV Drones for Combat Extended

Мод для RimWorld 1.7 добавляет одноразовый FPV-дрон и многоразовый разведчик «Мавик». Интерфейс доступен на русском и английском. Для работы нужны Harmony и Combat Extended.

## Установка

1. Распакуйте папку `FPVDrones` из архива в папку `Mods` игры. Проверьте, что файл описания находится в `Mods/FPVDrones/About/About.xml`.
2. В списке модов включите **FPV Drones for Combat Extended** и поместите его после **Combat Extended**. Harmony должен загружаться перед Combat Extended.
3. Перезапустите игру. После «Микроэлектроники» исследуйте «FPV-дроны», затем изготовьте очки, пульт и выбранный аппарат на станке для мехобработки. Игра автоматически выбирает рецепт одноразового дрона по настройке боеприпасов CE.

## Первый вылет

- Выберите колониста и щёлкните правой кнопкой по очкам, пульту и дрону. Для каждого предмета выберите «Взять в комплект FPV». Все три предмета должны находиться в инвентаре оператора.
- Мобилизуйте колониста. Нажмите «Запустить» для нужного экземпляра и выберите клетку оператора. До взлёта пешка дойдёт до указанного места. Камера переключится на аппарат.
- Щёлкните правой кнопкой по карте, чтобы задать маршрут. **Shift + ПКМ** добавляет путевую точку. Вы можете менять маршрут на паузе и переключаться между пешками. Кнопка «Выбрать дрон» возвращает камеру к аппарату.
- Для камикадзе доступна команда «Завершить полёт с подрывом». Подсветка показывает основной взрыв. Осколки CE могут выйти за его пределы.
- Для «Мавика» доступны «Сесть здесь» и «Вернуться». Во время автовозврата исходный оператор может нажать «Снова управлять», если комплект при нём и аппарат находится в радиусе связи.
- Чтобы зарядить «Мавик», постройте станцию, подключите её к сети и доставьте на её клетку севший разведчик. Его можно забрать до окончания зарядки. Станция расходует 100 Вт при зарядке и восстанавливает пустой аккумулятор за 60 секунд при скорости ×1.

## Исходный код

В `Source` находятся исходники C# и файл проекта. Сборка требует .NET SDK 10 и установленных RimWorld, Harmony и Combat Extended. Выполните `dotnet build Source/FPVDrones.csproj -c Release` из каталога мода. Для другой библиотеки Steam задайте `-p:RimWorldDir="путь к игре"` и `-p:WorkshopDir="путь к steamapps/workshop/content/294100"`. Готовая библиотека появится в `Assemblies`.
