# FPV Drones for Combat Extended

Мод для RimWorld 1.7 добавляет четыре одноразовых FPV-дрона, многоразовый разведчик «Мавик», РЭБ-рюкзак и операторов в крупных рейдах. Интерфейс доступен на русском и английском. Для работы нужны Harmony и Combat Extended. Simple Sidearms позволяет переключаться между оружием и пультом из списка запасного снаряжения.

## Установка

1. Распакуйте папку `FPVDrones` из архива в папку `Mods` игры. Проверьте, что файл описания находится в `Mods/FPVDrones/About/About.xml`.
2. В списке модов включите **FPV Drones for Combat Extended** и поместите его после **Combat Extended**. Harmony должен загружаться перед Combat Extended.
3. Перезапустите игру. После «Микроэлектроники» исследуйте «FPV-дроны», затем изготовьте пульт и выбранный аппарат на станке для мехобработки. Игра автоматически выбирает рецепт одноразового дрона по настройке боеприпасов CE.

## Первый вылет

- Выберите колониста, экипируйте пульт в основной слот и возьмите заряженный дрон в инвентарь. Снаряжение CE позволяет задать, сколько дронов каждого вида пешка пополняет из запасов колонии.
- Мобилизуйте колониста. Нажмите «Запустить» для нужного экземпляра и выберите клетку оператора. До взлёта пешка дойдёт до указанного места. Камера переключится на аппарат.
- Щёлкните ПКМ по свободной клетке, чтобы направить выбранные дроны. **Shift + ПКМ** добавляет путевую точку. Выбранный аппарат показывает остаток пути. Приказ движения оставляет пилота за пультом. Для осознанного выхода используйте «Прервать пилотирование».
- Щёлкните ПКМ по видимой вражеской пешке или постройке. Выбранные ударные дроны сами летят к цели, следуют за ней при движении и подрываются при подходе. Если цель уничтожена или выходит из зоны полёта, дрон останавливается и ждёт нового приказа.
- Для камикадзе доступна команда «Завершить полёт с подрывом». **J** подрывает все выделенные ударные дроны. Клавиша меняется в настройках управления в разделе **«FPV-дроны»**. Подсветка показывает основной взрыв, а осколки CE могут выйти за его пределы.
- Для «Мавика» доступны «Сесть здесь» и «Вернуться». Во время автовозврата исходный оператор может нажать «Снова управлять», если пульт в основном слоте и аппарат находится в радиусе связи.
- Чтобы зарядить «Мавик», постройте станцию, подключите её к сети и доставьте на её клетку севший разведчик. Его можно забрать до окончания зарядки. Станция расходует 100 Вт при зарядке и восстанавливает пустой аккумулятор за 60 секунд при скорости ×1.

## Выделение и группы

- Нажмите на маркер дрона на карте или на строку в боковой панели **«Дроны»**. Удерживайте **Shift**, чтобы добавить аппарат к выделению или убрать из него. **Alt + рамка левой кнопкой** выделяет только ваши дроны в полёте.
- **Ctrl + щелчок по кнопке 1–4** на панели записывает выделенные аппараты в группу. Обычный щелчок по номеру выбирает группу. **Ctrl + Alt + Z / X / C / V** записывает группы с клавиатуры, а **Alt + Z / X / C / V** выбирает их. Состав хранится в сохранении карты и привязан к конкретным вылетам.
- После выбора группы используйте обычный приказ ПКМ. Команда на клетку действует и на ударные дроны, и на «Мавики». При команде атаки «Мавики» продолжают свой полёт по текущему маршруту.
- Чтобы выстроить два или больше дронов в ряд, удерживайте **ПКМ на свободной клетке**, протяните линию и отпустите кнопку. Круги показывают места аппаратов. Дрону нужна доступная клетка в радиусе его пульта и достаточный заряд, чтобы добраться до неё.

## Рейды и РЭБ

Осколочные FPV используют эффект осколочного выстрела CE, а зажигательные — эффект Молотова CE. Надетый РЭБ-рюкзак прерывает полёт вражеских радиодронов в пределах 30 клеток. Его можно узнать по двум антеннам и бирюзовому индикатору. Оптоволоконные аппараты продолжают полёт в поле РЭБ. Любой аппарат можно сбить первым прямым попаданием CE.

Стрелки CE оценивают разведчики как обычные боевые цели, а ударные FPV получают повышенный приоритет на штатной дальности оружия. Рейдер с готовым оружием может остановиться во время обычной перебежки, чтобы прицелиться и дать штатный залп по дрону в зоне огня. Вражеские пешки с оружием ближнего боя и без оружия накапливают подавление CE в пределах 8 клеток от видимого ударного дрона. В пределах 3 клеток они сразу ложатся на землю по штатному заданию CE.

В крупных рейдах развитых фракций встречается до четырёх операторов, каждый может нести до четырёх ударных FPV. Пока есть подходящая цель и заряженные дроны, оператор предпочитает занять укрытие, запускать их по очереди и только потом возвращается к своему оружию. В режиме разработчика есть действие **Test raid with FPV operators** для игрового прогона.

## Исходный код

В `Source` находятся исходники C# и файл проекта. Сборка требует .NET SDK 10 и установленных RimWorld, Harmony и Combat Extended. Выполните `dotnet build Source/FPVDrones.csproj -c Release` из каталога мода. Для другой библиотеки Steam задайте `-p:RimWorldDir="путь к игре"` и `-p:WorkshopDir="путь к steamapps/workshop/content/294100"`. Готовая библиотека появится в `Assemblies`.
