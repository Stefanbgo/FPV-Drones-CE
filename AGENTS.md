# Обновления FPV Drones CE

- После каждого завершённого и проверенного обновления сделай отдельный коммит и отправь рабочую ветку на GitHub в `origin`. Проверь, что удалённая ветка указывает на этот коммит.
- Новые игровые механики разрабатывай в отдельной ветке. Стабильные версии сохраняй в `main` и отмечай тегом `vX.Y.Z`, который соответствует `modVersion` в `About/About.xml`.
- Для стабильной версии опубликуй GitHub Release с кратким списком изменений и установочным ZIP из соответствующего тега. Проверь, что архив содержит папку `FPVDrones` с DLL и игровыми ресурсами.
